Here's three tips to become a top 1% agent orchestrator. Number one, transcripts, transcripts, transcripts. No matter what agentic coding tool you are using, they all store transcripts of your exact conversations with the agent and all of the thinking and tool calls that your agent made. This is an absolute gold mine for observability and memory that a lot of people don't take advantage of. Hermes, which is a tool that a lot of people use, actually use session transcripts as searchable memory for their agent, which is why it gives it such good memory. Transcripts are an amazing way to audit and iterate on skills. So when your agent produces an output that you don't like from a certain skill invocation, you can go to the transcript, see it invoke the skill, see all of its thinking, see if it followed the steps of that skill correctly, and then take those mistakes that it might have made, go back and edit the skill.md file. Number two is agent self-awareness prompts. This is basically asking your agent to be aware of its own environment, its own tools, its own abilities, permissions, hooks, so that it can actually help you enable it to do things more autonomously. For instance, maybe you're configuring a database.
