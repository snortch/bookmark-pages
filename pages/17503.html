Claude code has a new feature that reduces its token consumption, makes Claude smarter and makes your Claude setup way more efficient. This is the new checkup feature and here are the seven things that it does. To run a checkup, just type in /checkup to Claude code. The first thing it does is looks through your Claude code's history to see which skills, MCPs and plugins Claude is or isn't using, and then cleans up unused ones to reduce context consumption. Secondly, it goes through your user level, project level and local claude.md files and dedupes them against each other. Then, if your claude.md files are too long, which most of yours probably are, it splits your single claude.md file into nested claude.md files that are more specific. You'll be shocked at how much just these first three points reduce your baseline context consumption when you start up Claude code in a folder because it allows Claude to progressively disclose the information that it needs when it needs it. Number four, it tests all of your Claude code hooks to make sure none of them are too slow and if they are, it makes them more efficient. Number five, it automatically updates Claude to make sure you're up to date. Sixth, it configures your Claude to have auto mode on by default so you don't have to start up Claude
