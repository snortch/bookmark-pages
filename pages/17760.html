This new cloud code slash command allows you to deploy hundreds of agents in parallel at the same time. It takes advantage of the new agents view and tools where one session can spawn up multiple other agents that are full sessions that work in the background. Slash batch is the built-in cloud code skill that helps you orchestrate dozens to hundreds of agents for really large complex code base changes. To run it, you can type in slash batch to the cloud code CLI with a space and then your instructions for that batch process. The session you're working in will then do a comprehensive research and exploration process of the code base you're working in, basically to plan out the different scoped tasks for all the agents that will be deployed in this batch process, the contracts between them, and how the whole thing will be validated in the end. This results in dozens of scoped subtasks, each of which will be sent to a full cloud code session running in the background, working on its own Git work tree. The initial research process designs each scope task to not overlap with one another and to have contracts where the code interacts between subtasks. Similar to dynamic workflows, this is a great way to parallelize work between many agents and manage them altogether.
