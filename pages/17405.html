Guys, the Chrome Dev Tools MCP is insane for front-end development. It basically gives your agent X-ray vision into your browser while you're testing the front-end that you're developing, so your agent can see a ton of different metadata, logs, errors about that front-end you're developing. It has a get console logs tools so you can actually see runtime errors, stack traces, hydration issues, and a bunch of other stuff. It can see failed API calls, it can see incorrect auth headers, it can see cores errors. You can see if there are missing assets in your front-end, if there are wrong payloads, just a ton of different metadata from those logs. It can also do something called DOM inspection, which means it can actually see what the browser rendered, not just what your like React or view code was trying to render. It can also inspect things like session cookies if that's relevant to the front-end you're making, things like auth state, persistence issues, local storage, session storage, so many things. Pairing something like this with something like the Playwright CLI or Playwright MCP unlocks an extra superpower.
