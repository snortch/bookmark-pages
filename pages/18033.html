Built for macOS, Xirp lets developers run Claude Code, Codex, and Gemini across multiple projects in persistent terminal sessions. Each task can use its own Git worktree, allowing agents to work in parallel without touching the same checkout. The more interesting part is context. When connected to Spotify Portal, Xirp can give agents access to a company’s software catalog, documentation, decisions, workspace resources, and previous session transcripts through MCP. Instead of starting every coding session with “here’s what this codebase does,” teams can give agents a real map of how their systems fit together. It is still in beta, but it points toward a more serious version of AI-assisted development: not one agent in one chat, but persistent, context-aware agent work across an entire engineering organization.
