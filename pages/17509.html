So I've been using GSD with Claude Code workflows. You guys should really try it. The point of GSD is to make structured plans that are really complicated and then shard those plans out into smaller, more specific tasks to be tackled by one sub-agent. Claude Code workflows can actually absorb some of that complexity because they provide the structure to allow you to have multiple sub-agents in a structured loop. Instead of using one big GSD process at the beginning of your project to create that big plan, chart out all of your tasks and sub-tasks, you can kind of encapsulate a mini GSD process within each Claude Code workflow, and maybe each Claude Code workflow is assigned to a phase of your project. Claude Code workflows are meant for having sequences of sub-agent phases, which is perfect for GSD, so you can have research phases, discovery phases, planning phases, implementation phases, review and implementation loops that finalize themselves in a PR. You can point a Claude Code session at the GSD skills and slash commands and ask them to take those and turn them into sub-agent prompts in a Claude Code workflow file. This kind of pulls you as the user another level of abstraction above what your agents are actually doing during a GSD loop, and it allows you to run multiple loops in parallel so you can get even more specific and granular with your projects.
