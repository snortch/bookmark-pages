[VIDEO] Cloudco just got two new tools that allow it to send a message to any other cloud session running on your computer, a session running in the cloud, or a session running on a different computer anywhere in the world. Tool number one is the list agents tool, which allows your cloud session to basically see what other cloud sessions are running under this account. This is not just sessions running locally on your computer, it's sessions locally, sessions in the cloud, or remote control sessions from another computer on your account. The second tool is the send message tool, so once a user's list agents finds an agent to message, it uses the send message tool to send a plain text message that arrives in the receiving agent's inbox socket. I think the biggest unlock here is true cross-environment coordination between cloud sessions. So you can have cloud sessions running, you can have sessions running on multiple computers, and all of those sessions can function as one hive mind. To make cross-machine sessions discoverable, you have to use remote control. So they're basically using remote control and Anthropic servers as a messaging bus. There's a ton of different applications for this type of cross-environment messaging, both development and business facing.
