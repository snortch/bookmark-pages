[CAPTION] AI coding agents don’t usually fail because the task is “too hard.” In this clip, Matt Pocock points at a simpler failure mode: we hand agents horizontal plans—database first, API next, frontend last—and they code layer by layer without an integrated feedback loop. His fix is an old software idea from The Pragmatic Programmer: tracer bullets, or vertical slices. Instead of asking the agent to build one layer at a time, create thin tasks that cross the database, service/API, and frontend enough to prove the whole flow works.
