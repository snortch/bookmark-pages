Anthropic ships two production patterns for pairing Fable 5 with Sonnet 5 — advisor and orchestrator — and the cost curves aren't the same shape. - Advisor: Sonnet 5 executes every turn and calls Fable 5 (no parameters, full transcript auto-forwarded) only at hard decision points — advisor tool, beta header advisor-tool-2026-03-01 - Orchestrator: Fable 5 plans and fans out to parallel Sonnet 5 workers via the multiagent coordinator field — each worker holds its own tools and its own context thread - Anthropic documented April 9 benchmark (Sonnet 4.6 + Opus 4.6 advisor) showed +2.7pp on SWE-bench Multilingual at -11.9% cost — the newer Fable 5 + Sonnet 5 SWE-bench Pro and BrowseComp figures circulating are from Anthropic dev account, not yet in the docs or a blog post If the workload is one long session with occasional hard calls — coding, computer use — advisor mode keeps Fable 5 on standby instead of running full-time. If the workload is fan-out reading — verifying claims across sources, sweeping a codebase — orchestrator mode moves the token-heavy part to the cheap model entirely. Both run on the same Managed Agents sub-agent primitive, so the infrastructure decision and the pattern decision are separate calls.
